# UI 一致性基线 baseline v1

> 来源：用户授权"按建议采用"阶段 0/1 草案默认值。
> 用途：gate 模式的判定依据。任何修改本文件的阈值、令牌或白名单，都需单独记录原因与复审日期。

## 1. 间距令牌（dp）

| 令牌 | 值 | 用途 |
| --- | --- | --- |
| `Spacing.xs` | 4 | 图标与文字、紧凑内部间隔 |
| `Spacing.sm` | 8 | 组内元素、标题与内容 |
| `Spacing.md` | 12 | 卡片内部块间距、示例区间距 |
| `Spacing.lg` | 16 | 面板/分组内部水平 padding、卡片之间 |
| `Spacing.xl` | 20 | 卡片内边距、TopBar 水平 padding |
| `Spacing.xxl` | 24 | 页面内容水平 padding、组间间距 |
| `Spacing.xxxl` | 32 | 大区块分隔 |

微调白名单：`2 / 3 / 5 / 6 / 10 / 14 dp` 仅允许保留在组件内部细节（图标间距、分隔线附近、紧凑标签行），不得用于页面或卡片主间距。复审日期：下次视觉改版。

## 2. 容器规则

| 层级 | 水平 padding |
| --- | --- |
| 页面内容 | 24 |
| 面板 / 分组内部 | 16 |
| 选项框 / 紧凑行 | 14（白名单，复审日期同上） |
| 卡片内边距 | 20；实验室紧凑预览卡片允许 16（例外，复审日期同上） |

- 同一容器的左右 padding 差 = 0（允许 ≤0.5dp 舍入）。
- 同层容器左边缘 x 差 ≤0.5dp。
- 同组按钮、底部导航两项宽度差 = 0。

## 3. 圆角令牌（dp）

| 场景 | 值 |
| --- | --- |
| 小控件 / 输入框 / 小标签 | 12 |
| 选项框 / 小卡片 | 16 |
| 大卡片 / 弹窗 | 24 或 28（同一页面只能一档） |
| 玻璃面板 / 玻璃卡片默认 | 32（`LiquidGlassTuning.cornerRadiusDp`） |

`4 / 8 / 10 / 14` 仅允许作为组件内部细节白名单。

## 4. 字体

- 默认使用 `MaterialTheme.typography`。
- 直接 `fontSize = N.sp` 仅允许白名单：余额大数字（57/45/36）、组件内部固定标签（14/15/16/12/13/11）。
- 同行标签与数值 `firstBaseline` 差 ≤1dp；图标与伴随文字垂直中心差 ≤1dp。

## 5. P0 规则

1. 非滚动容器不得裁切子元素。
2. 声明的关键元素对不得遮挡：首个用例为 `lab:preview:sampleButton` 与 `lab:panel:root`，要求相交面积 = 0。
3. 滚动容器中的关键操作必须可滚动到达；默认配置（360×800dp、浅色、fontScale 1.0）下实验室示例按钮必须完整位于预览视口内。
4. 非声明文本溢出 = P0；有意的 `maxLines + Ellipsis` 走白名单。
5. 左右 padding 不对称、同组元素不等宽 = P0。

## 6. P1 / P2

- P1：令牌外取值、同层左边距不一致、指定间距超阈值、基线/中心线超阈值。
- P2：留白、信息密度、玻璃质感、视觉重心、动效手感，由人工评审。

## 7. 通过判定

- P0 = 0，且不存在未说明的 `blocked/skip`。
- P1 必须登记到 `summary.md` 并给出处理期限。
- 任何 `blocked` 都不算产品缺陷，但也不得计入"已验证"。
